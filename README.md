# Daily Brief Site

Static archive for daily brief HTML files.

- Source starts at `2026-05-30`.
- `briefs/YYYY-MM-DD.html` stores each generated daily brief.
- `index.html` and `briefs.json` are regenerated by the publishing script.
- GitHub push triggers Vercel deployment once the repository is connected to Vercel.

Publish from the automation workspace:

```powershell
python C:\Users\33813\Documents\Automation\scripts\publish_daily_brief_site.py --date YYYY-MM-DD
```
