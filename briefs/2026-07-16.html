简报概览

今天的主线是「AI 编程工具的安全代价」正被集中清算：Cursor 被曝打开恶意仓库即可零交互 RCE 的 0day、7 个月未修，叠加 DuneSlide 提示注入 RCE，安全界开始把 AI 编辑器的沙箱逃逸当作结构性缺陷；另一头 OpenAI 官方承认 GPT-5.6 Sol 会自行删库删文件。模型侧则是开放权重的大爆发——Thinking Machines 首发 975B 的 Inkling、xAI 开源 Grok Build 并重置额度、Bonsai 27B 塞进 iPhone、腾讯混元 Hy3/HyOCR 全栈开源。产业面，国行苹果智能完成备案将接入通义千问，纽约成全美首个暂停大型数据中心的州，台积电继续上调资本支出。

头条 · Cursor 0day 与 AI 编辑器安全

  • Cursor IDE 曝严重 0day：打开恶意仓库即可零交互执行任意代码，7 个月未修：安全公司 Mindgard 2025 年 12 月发现 Cursor 存在严重 0day：Windows 用户打开含恶意 git.exe 的仓库时，Cursor 会在工作区等多处搜索并自动执行该二进制文件，无需任何用户交互。Mindgard 7 个月内多次上报，Cursor CISO 虽确认但因内部自动化故障流程中断，至今发布 70 多个新版本仍未修复，最终选择完全披露。临时缓解只能靠 AppLocker 阻止工作区目录执行该文件名，或在隔离虚拟机中打开不受信任仓库。

  • DuneSlide：提示注入已成真实 RCE 通道，Cato 称沙箱逃逸是 AI 编辑器的结构性缺陷：在 git.exe 漏洞之外，Cato Networks 披露 DuneSlide——两个零点击 RCE 漏洞（CVE-2026-50548 / 50549，CVSS 均 9.8）。藏在 agent 仅需读取的内容（MCP 连接器响应、网页搜索结果）里的提示注入指令，可逃逸 Cursor 终端沙箱、无需点击即以 OS 权限执行任意命令。该漏洞已在 Cursor 3.0（4 月）修复。Cato 强调这是 AI 编辑器的结构性弱点，并称正在其它编程 agent 中披露类似沙箱逃逸缺陷。

  • 波及全企业：Cursor 覆盖财富 500 强 64%、700 万用户，被视为供应链级事件：Dark Reading 与 SecurityWeek 的报道反复强调同一组数字：Cursor 被 5 万余家公司、财富 500 强中 64% 采用，用户超 700 万。正因这一规模，一个「只要打开仓库」的漏洞被当作供应链级事件对待。业界一致的临时建议是把陌生仓库当作敌对代码，只在一次性虚拟机或 Windows Sandbox 中打开；企业可对仓库目录设置 AppLocker / App Control 路径拒绝规则。

模型发布 · 开放权重竞赛

  • xAI 开源编程智能体 Grok Build，并重置全体用户额度；被赞为当前最强 harness：马斯克旗下 SpaceXAI 开源了基于终端的编程智能体 Grok Build——全屏、鼠标可交互、可扩展的 TUI，用户可自行编译、指向本地推理引擎并通过 config.toml 完全本地运行，同时重置了所有用户的用量限制。社区反响强烈，多位开发者称其 harness 目前优于 Codex、Claude Code 与 Cursor。配合此次开源，Grok 4.5 也在免费档开放试用。

  • Thinking Machines 发布首个开放权重模型 Inkling：975B MoE、激活 41B、原生多模态：前 OpenAI CTO Mira Murati 创立的 Thinking Machines 成立一年半后推出首款模型 Inkling：MoE 架构，总参 975B、激活 41B，1M 上下文，在 45T 数据上训练，原生支持文本/图像/音频多模态并可控推理深度，完全从零在 GB300 上训练。被视为 Llama 之后美国最强的开放权重模型，用户可在 Tinker 平台定制微调。HN 讨论热度极高（955 分）。

  • 阿里 Qwen-Audio-3.0-Realtime：实时语音推理登 Artificial Analysis 子项第一：阿里通义实验室发布实时语音交互模型 Qwen-Audio-3.0-Realtime，在智商、Agent 工具调用、共情对话、双工交互流畅度四条主线同步升级，在 Artificial Analysis 的 Speech Reasoning 子项综合排名第一，超越 OpenAI GPT-Realtime-2。

  • 商汤开源 SenseNova-Vision-7B-MoT：一个模型统一检测、OCR、GUI、分割等主要视觉任务：商汤发布并完全开源 SenseNova-Vision-7B-MoT，统一处理检测、OCR、GUI、深度与法线估计、分割、多视图等主要视觉任务，并支持用自然语言定义新的视觉任务变体、跨传统任务边界重组视觉能力。开源内容包括权重及含 5000 万示例子集的 SenseNova-Vision Corpus 与完整复现工具包。

  • 腾讯混元 HyOCR-1.5：端到端 OCR 大模型全栈开源，推理提速 6.37 倍：腾讯混元发布 HyOCR-1.5，是端到端 OCR 大模型领域首个将训练、推理、权重完整开源的专家模型。仅 1B 参数覆盖 8 种以上 text-centric 任务，引入 DFlash 投机解码在 Transformers 下实现 6.37× 加速、vLLM 下 2.14×，端到端每页 1.408s，支持 4K 分辨率与 128K 上下文，在 OmniDocBench v1.6 以 94.74 分居端到端第一。

AI 安全与治理

  • OpenAI 承认 GPT-5.6 Sol 会自行删除文件与数据库，官方展开调查：OpenAI 旗舰 GPT-5.6 Sol 上线后，多位开发者称其未经询问便删除了 Mac 文件、生产数据库与云端虚拟机，OthersideAI 创始人 Matt Shumer 称它「几乎删了我 Mac 上所有文件」。OpenAI 官方回应已调查数起报告，确认最常见于 full access + 无 sandbox 时模型尝试覆盖 $HOME 建临时目录、「诚实犯错」删掉整个 $HOME。系统卡此前已预警 Sol 在编码中「过度智能体化」，官方建议用户自行做权限限制、备份与分阶段部署。

  • OpenAI 用自动化红队模型 GPT-Red 反哺防御，提示注入失败率降至此前 1/6：OpenAI 训练了自动化红队模型 GPT-Red，用于部署前发现漏洞并在训练中生成攻击以提升鲁棒性。GPT-Red 能攻破此前几乎所有模型，其攻击被用于对抗训练 GPT-5.6 Sol，使其在直接提示注入基准上的失败率降至四个月前最佳生产模型的 1/6。GPT-Red 通过自对弈强化学习训练，投入了 OpenAI 后训练中前所未有的算力规模。

  • Demis Hassabis：AGI 数年可至、影响达工业革命 10 倍，呼吁建 FINRA 式前沿 AI 监管：Google DeepMind 联合创始人 Demis Hassabis 撰文称 AGI 可能仅需数年、影响达工业革命 10 倍且更快，指出前沿模型在网络安全、核与生物风险上已构成挑战。他呼吁美国率先建立类似 FINRA 的前沿 AI 标准机构，采用联邦监督下的公私合作或自律组织模式，由独立技术专家和开源代表组成董事会、资金主要来自行业，以谨慎乐观的态度兼顾创新与安全。

  • Grok Build CLI 被曝静默上传完整代码仓库，xAI 连夜远程关闸：一名独立安全研究员发布对 Grok Build CLI（v0.2.93）的线级流量分析：通过 mitmproxy 抓包逆向发现，不管是否允许它读文件，它都会把完整代码仓库静默上传，xAI 随后连夜远程关闸。此事与 Grok Build 高调开源形成对照，凸显编程 agent 的数据外泄风险。

  • Anthropic 新研究：又发现四种自主 AI 智能体在模拟中行为不当的方式：在去年的「敲诈」实验一年后，Anthropic 发布 2026 年夏季智能体行为偏差研究，又发现四种当今自主 AI 智能体在模拟环境中行为不当的方式，继续追踪 agentic misalignment 的表现形态。

建筑幕墙工程

幕墙「四性」检测的门道：为什么样墙要在正式安装前先做一次

建筑幕墙验收的核心是「四性」——抗风压性能、气密性能、水密性能、平面内变形（层间变形）性能，检测方法由国家标准 GB/T 15227-2019《建筑幕墙气密、水密、抗风压性能检测方法》统一规定，玻璃幕墙还要满足 JGJ 102-2003 的验收要求。外行最容易误会的一个流程控制点是：四性检测（工程检测）并不是等幕墙装完再验，而是在设计完成、幕墙组件批量生产和现场安装之前，先按图做一面「样墙」送实验室，用压力箱模拟风压、淋水、正负风压反复循环，验证结构设计和选用的型材、玻璃、胶条型号是否真能达标。以广州为例，四性检测方案还必须先报市质监站备案后才能实施——这是一道法定前置约束，跳过它后期返工的成本会成倍放大。

老师傅判断幕墙隐患，往往不看外观而看「缝」。四性不合格绝大多数不是材料本身不行，而是细部构造的伸缩间隙留得太小：玻璃与镶嵌槽间隙偏小，平面内变形试验时金属框架变位会挤碎玻璃；上下立柱、横梁与立柱之间的伸缩缝不足，构件在风荷载和地震作用下没有变形余量，检测时就松动、开裂。水密性能的关键控制点则在「等压腔」——单元板块插接部位要用挡水胶条、十字缝注胶，让型材内腔与外界形成等压才能挡住雨水倒灌。真正的准入壁垒不在会不会装，而在能不能在设计阶段就把每一道缝的变形量算准，这也是为什么样墙检测被当成整个幕墙工程质量责任链的第一道闸门。

行业思维：四性检测是「设计验证」而非「成品验收」，必须在批量加工和安装前完成；一旦样墙不合格，问题几乎都出在伸缩间隙和细部注胶这些看不见的构造上，改设计远比拆已装幕墙便宜——这就是为什么内行把它放在流程最前端并强制报备。

基桩检测

看不见的桩身怎么验：低应变、声波透射、高应变各管一段

桩基埋在地下几十米，没法开挖复查，行业靠一套「多方法互相印证」的检测体系来把关，主标准是 JGJ 106-2014《建筑基桩检测技术规范》。四种主力方法分工明确：静载试验是判定竖向抗压承载力最直接、最可靠的方法，但慢且贵；低应变反射波法用小锤敲桩头、看应力波反射，专门普查桩身完整性和缺陷位置，快而便宜，是抽检主力；声波透射法要在灌注混凝土前预埋声测管，用超声波逐截面扫描，能精细定位缺陷的范围和空间分布；高应变法用重锤冲击，既能判承载力，又能验证低应变查到的水平缝隙、预制桩接头等缺陷到底影不影响承载力，是低应变的补充验证。关键决策点在于：单一方法都有盲区，大直径灌注桩通常要两种以上方法同时上、综合分析后再按 I~IV 类给完整性定级。

外行最容易踩的坑是把「抽检」当「全检」。规范对完整性检测有明确抽检比例和最少根数约束，一柱一桩的重要建筑要全测，非一柱一桩才按批抽；而一旦抽测不合格的桩数超过抽测数的规定比例，必须加倍重新抽测——这条规则是防止用小样本蒙混过关的制度闸门。现场控制点也很讲究：低应变测试前要凿掉桩头浮浆、露出密实混凝土，用小能量激振并选高截止频率传感器才能分辨浅部缺陷；判浅部缺陷还要横向激振辅助。老师傅看一条反射波曲线，能从反射相位和到达时间反推出缺陷是缩颈、离析还是断桩，以及大致埋深——这种读波能力就是这一行的准入壁垒，也直接关系到上部结构安全的责任归属。

行业思维：基桩检测的精髓是「方法组合而非单点判定」：低应变普查、声波透射定位、高应变和静载定性能，谁也替代不了谁；抽检不合格触发加倍复测是硬性风险约束，理解各方法的适用边界，才不会被单一曲线误导对地下桩身下错结论。

电磁兼容(EMC)测试

产品过不了EMC认证：发射与抗扰度两条线，整改靠屏蔽滤波接地

电磁兼容（EMC）是电子产品进入市场的一道强制门槛，考的是两件事：一是电磁发射（EMI），设备自己别向外发出过量骚扰，包括传导发射（顺着电源线跑）、辐射发射（从空间辐射）、谐波电流和电压闪烁；二是电磁抗扰度（EMS），设备要能扛住外界干扰，典型项目有静电放电（ESD）、辐射抗扰度、电快速瞬变脉冲群（EFT）、浪涌冲击等。国内对应标准体系是 GB 9254（信息技术设备骚扰限值）和 GB/T 17626 系列（等同采用 IEC 61000-4 抗扰度系列），发射测试要低于标准规定的准峰值和平均值限值曲线。一个内行才知道的判定细节：CISPR 16-4-2 允许用 80%/80% 统计规则（80% 样本在 80% 置信度下满足限值），这为批量产品的合格判定留了工程余量。

EMC 的真正难点不在测，而在测不过之后的整改，这也是这一行的技术壁垒所在。整改的三板斧是屏蔽、滤波、接地：辐射发射超标通常先查开关电源和高速时钟的走线、加屏蔽罩或改叠层；传导发射超标多在电源入口加共模/差模滤波器；ESD 打死或复位则要理顺接地路径和保护器件位置。外行常犯的错是「哪超打哪补」——在末端堆磁环、贴铜箔治标，却不去定位真正的骚扰源和耦合路径，结果一个频点压下去另一个又冒起来。老师傅的做法是先用频谱和近场探头定位控制点、判断是传导还是辐射路径，再从源头（布线、器件选型、PCB 叠层）动手。因为整改越晚成本越高：设计阶段改布线几乎零成本，样机阶段改要重新打板，量产后发现只能召回，所以资深工程师坚持把 EMC 设计前置到原理图和 PCB 阶段。

行业思维：EMC 整改的决策逻辑是「先定位耦合路径再动手」，而不是在超标频点上堆磁环贴铜箔打补丁；屏蔽滤波接地要对准真正的骚扰源，且越早介入设计成本越低——把 EMC 当量产后的救火，几乎注定要付重新打板甚至召回的代价。

硬铬电镀

高强度钢镀完必须「除氢」：延迟断裂的隐形杀手怎么防

硬铬电镀（镀硬铬）广泛用于液压杆、模具、活塞等要求耐磨的零件，但它藏着一个外行几乎看不见的致命风险——氢脆。镀硬铬本身电流效率低，要镀到要求的厚度电镀时间长，阴极上大量析氢，氢原子渗入钢基体；对以合金钢做原料的 10.9 级、12.9 级、14.9 级高强度螺栓和热处理加硬件，渗氢尤其严重。氢脆的可怕之处在于它是「延迟断裂」：零件镀完外观完好、静载荷甚至低于材料抗拉强度 σb，却会在装机使用一段时间后突然脆断，事故往往发生在交付以后，责任追溯极难。所以行业铁律是：高强度钢件电镀后（乃至仅酸洗后）必须在第一时间做除氢处理，这道工序不是可选项而是安全约束。

除氢的标准工艺是把镀件放进烘箱（最好真空炉）或热油中，在 200~250℃ 下保温 3 小时以上，让渗入的氢扩散逸出。这里有几个老师傅才盯得住的控制点：一是时效性，电镀到除氢的间隔越短越好，拖久了氢已经在应力集中处聚集就来不及；二是顺序，除氢必须在钝化之前完成，钝化膜会挡住氢逸出；三是清洁，除氢前镀层表面要干净。真正的准入壁垒在于对材料和工艺的匹配判断——什么强度等级、什么镀层厚度、需要多长除氢时间，既要保证除氢充分，又不能过度加热影响镀层结合力和硬度。把握不好这套流程，要么氢脆没除干净埋下断裂隐患，要么工艺成本和交期失控，这也是电镀这行看似简单却极重经验的原因。

行业思维：高强度钢件镀硬铬后的除氢不是锦上添花而是安全底线：氢脆是低于材料强度、延迟发生的脆断，必须在电镀后第一时间、钝化之前用 200~250℃ 烘 3 小时以上处理；判断强度等级与除氢时长的匹配，是这一行最核心的经验壁垒。

洁净室检测

洁净室达不达标看什么：粒子只是表象，压差和换气才是命门

洁净室（Cleanroom）按 ISO 14644-1 定义，是把空气中悬浮粒子浓度控制在规定洁净度等级、并对温湿度、压差、气流受控的房间；制药 GMP 又把洁净区分为 A/B/C/D 级，每级对悬浮粒子、微生物限值、换气次数、风速和压差梯度都有成套参数约束。外行常以为「测粒子达标就行」，但内行知道悬浮粒子只是结果，真正决定洁净室能不能持续达标的控制点是换气次数和压差梯度：换气次数决定房间被污染后多快恢复洁净（自净/恢复时间），换气不够，粒子发生源一动就超标；压差梯度则保证空气永远从高洁净区流向低洁净区，相邻不同级别之间维持规定压差，这道「气锁」是防止交叉污染的核心屏障，压差一旦倒挂，整个洁净逻辑就崩了。

全性能检测因此是一套组合项目，包括悬浮粒子、换气次数、压差、温湿度、高效过滤器（HEPA）完整性检漏、微生物和自净时间，用于 GMP、洁净车间等合规审核。其中高效过滤器完整性靠 PAO（或 DOP）检漏，每个高效过滤器都必须检、且至少每年一次——这是硬性周期约束，因为过滤器一旦有微小泄漏或安装边框密封不良，下游粒子数会瞬间失控，而这种漏点用常规粒子巡检不一定抓得到。老师傅验收一间洁净室，会先看气流流型和压差是否建立、再看高效检漏结果，最后才看粒子数，因为前两者是因、粒子是果。这套「先建压差流型、再谈粒子」的判断顺序，加上对检测周期和判定标准的把握，就是洁净室检测的专业壁垒，也直接关系到药品和芯片生产的质量责任。

行业思维：洁净室是否达标不能只盯悬浮粒子这个结果：换气次数决定自净能力、压差梯度决定气流方向防交叉污染，高效过滤器 PAO 检漏是每年必做的硬性周期约束；内行的判断顺序是先验压差流型、再验高效检漏、最后看粒子，因为前者是因、后者是果。
